Reply detection setup 回复检测设置

The CRM never reads your mailbox. A forwarding rule sends candidate replies to the endpoint below, and anything that is not a reply to a CRM-sent email is discarded on arrival.
CRM 不读取您的邮箱。转发规则仅发送候选回复，非 CRM 邮件的回复会被直接丢弃。
Outlook / Microsoft 365: Rules → apply to messages that are replies → forward to a connector (Power Automate “When a new email arrives” → HTTP POST).
Payload: pass the message headers as headers (Message-ID, In-Reply-To, References, From, Date) plus a short snippet. Bodies are not required and are not stored.
Privacy: the token only allows offering a message. It grants no read access, and an unmatched message is refused.
